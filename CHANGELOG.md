# Changelog

All notable changes to this application are documented in this file.

## 0.1.3

- Settings: warning and info callouts span the full width

## 0.1.2

- Items are saved without an `id`; `id` is reserved as an attribute key
- Settings: the Options column only appears for Select attributes; the currency code input is removed (currency defaults to EUR)
- Record widget: Add item is centered, with the save status below it

## 0.1.1

- Record widget autosaves (no Save/Discard buttons); rows with empty required values stay a draft until filled
- Widget inputs use the plain, borderless style of record fields; widget aligns with the Fields card
- Pickers use Twenty UI Dropdown instead of Select, which the front component sandbox clipped
- Settings: repeater cards get a header with a "⋯" menu holding Remove repeater

## 0.1.0

- Initial application scaffolded with `twenty app init`
